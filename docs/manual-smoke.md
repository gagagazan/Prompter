# v0.1 人工跨平台 Smoke

在 macOS 13+ 的 Apple Silicon 与 Intel 构建、Windows 10 22H2+ / 11 x64 上分别执行。

## 首次启动与资料库

- [ ] 无配置启动时明确要求选择根目录；取消后仍可进入“管理文件库”。
- [ ] 根目录卸载、改名或权限移除后显示可恢复错误，不崩溃、不创建新目录。
- [ ] 更换根目录前有 dirty 编辑时阻止切换并提示处理草稿。
- [ ] `.PROMPT`、symlink/junction、`.git` 内容不进入文件列表。
- [ ] UTF-8 BOM、LF 与 CRLF 文件保存后保持原形式；非法 UTF-8 明确报错。

## 启动器与窗口

- [ ] 默认快捷键在两平台唤起当前显示器上的启动器。
- [ ] 快捷键被其他应用占用时给出明确错误，原有效快捷键不会丢失。
- [ ] 连续修改快捷键、反复注册、睡眠唤醒和显示器切换后仍只触发一次。
- [ ] 方向键、Enter 复制并关闭、Esc 关闭均工作；只复制，不自动粘贴。
- [ ] 从非前台应用点击托盘的管理器或设置，窗口会激活并置前。
- [ ] 关闭管理器只隐藏；托盘“退出”才终止进程。
- [ ] 托盘“退出”先显示未保存编辑警告；取消后应用继续运行。

## 编辑与外部工具

- [ ] clean 文件被外部编辑器或 Git checkout 修改时自动重载。
- [ ] dirty 文件被外部修改时草稿不丢失，保存被冻结，可重新载入或另存。
- [ ] 重命名、移动和创建遇到大小写/Unicode 跨平台冲突时拒绝覆盖。
- [ ] 文件“打开”无默认关联时保持可恢复，并可用“在 Finder/Explorer 中显示”。
- [ ] 文件夹含未管理文件、链接或不可读条目时不能整目录移入废纸篓。
- [ ] 回收站不可用时不回退为永久删除。

## 视觉与语言

- [ ] 三个窗口在 100% 和 200% 缩放下无裁切、重叠或水平滚动。
- [ ] 简体中文与 English 切换后完整刷新并在重启后保持。
- [ ] 编辑器仍是纯文本 textarea，没有 Markdown 预览或格式工具栏。
